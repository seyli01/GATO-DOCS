## What are reaction roles?

Reaction roles are roles that are assigned to members when they react to a message.
This can be useful for letting members choose unique roles or as a way to verify themselves.

## Create a reaction role

    <Tabs defaultValue="syntax" className="pt-3 pb-0.7">
        <TabsList>
        <TabsTrigger value="syntax">Syntaxe</TabsTrigger>
        <TabsTrigger value="example">Exemple</TabsTrigger>
        </TabsList>
        <TabsContent value="syntax">
        ```plaintext
        ,reactionrole add (message link) (emoji) (role)
        ```
        </TabsContent>
        <TabsContent value="example">
        ```plaintext
        ,reactionrole add .../channels/... ✅ @Member :smile: @role
        ```
        </TabsContent>
    </Tabs>

## Removing a reaction role

To remove a reaction role, you can use the `reactionrole remove` command.

    <Tabs defaultValue="syntax" className="pt-3 pb-0.7">
        <TabsList>
        <TabsTrigger value="syntax">Syntaxe</TabsTrigger>
        <TabsTrigger value="example">Exemple</TabsTrigger>
        </TabsList>
        <TabsContent value="syntax">
        ```plaintext
        ,reactionrole remove (message link) (emoji)
        ```
        </TabsContent>
        <TabsContent value="example">
        ```plaintext
        ,reactionrole remove .../channels/... ✅
        ```
        </TabsContent>
    </Tabs>

## Remove all reaction roles from a message

To remove all reaction roles from a message, you can use the `reactionrole removeall` command.

    <Tabs defaultValue="syntax" className="pt-3 pb-0.7">
        <TabsList>
        <TabsTrigger value="syntax">Syntaxe</TabsTrigger>
        <TabsTrigger value="example">Exemple</TabsTrigger>
        </TabsList>
        <TabsContent value="syntax">
        ```plaintext
        ,reactionrole removeall (message link)
        ```
        </TabsContent>
        <TabsContent value="example">
        ```plaintext
        ,reactionrole removeall .../channels/...
        ```
        </TabsContent>
    </Tabs>

## Remove all reaction roles from the server

To remove all reaction roles from the server, you can use the `reactionrole clear` command.

    <Tabs defaultValue="syntax" className="pt-3 pb-0.7">
        <TabsList>
        <TabsTrigger value="syntax">Syntaxe</TabsTrigger>
        <TabsTrigger value="example">Exemple</TabsTrigger>
        </TabsList>
        <TabsContent value="syntax">
        ```plaintext
        ,reactionrole clear
        ```
        </TabsContent>
        <TabsContent value="example">
        ```plaintext
        ,reactionrole clear
        ```
        </TabsContent>
    </Tabs>

<Note type="danger">
  This command will remove all reaction roles from the server and delete all
  reaction role messages. **This can't be undone.**
</Note>
