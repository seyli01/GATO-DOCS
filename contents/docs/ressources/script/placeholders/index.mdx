# Placeholders

All available variables within Gato.

Placeholders are variables that can be used in embeds or raw responses
to display specific information.
They are available for commands like `welcome`, `goodbye`, etc.

Here is the list of available placeholders per category:

<Tabs defaultValue="Guild" className="pt-3 pb-0.7">
      <TabsList>
        <TabsTrigger value="Guild">Guild</TabsTrigger>
        <TabsTrigger value="User">User</TabsTrigger>
        <TabsTrigger value="Channel">Channel</TabsTrigger>
        <TabsTrigger value="Lastfm">Lastfm</TabsTrigger>
        <TabsTrigger value="Leveling">Leveling</TabsTrigger>
        <TabsTrigger value="Moderation">Moderation</TabsTrigger>
      </TabsList>

      <TabsContent value="Guild">
        - `{guild.name}`                 - Server name
        - `{guild.id}`                   - Server ID
        - `{guild.count}`                - Total member count
        - `{guild.owner_id}`             - Server owner ID
        - `{guild.boost_count}`          - Number of boosts
        - `{guild.boost_tier}`           - Server boost level (e.g., Level 1)
        - `{guild.preferred_locale}`     - Server locale
        - `{guild.emoji_count}`          - Total emojis
        - `{guild.role_count}`           - Total roles
        - `{guild.channels_count}`       - Total channels
        - `{guild.text_channels_count}`  - Text channels count
        - `{guild.voice_channels_count}` - Voice channels count
        - `{guild.category_channels_count}` - Category channels count
        - `{guild.afk_timeout}`          - AFK timeout in seconds
        - `{guild.max_members}`          - Max members limit
        - `{guild.vanity}`               - Vanity URL code
        - `{guild.key_features}`         - Notable server features
        - `{guild.icon}`                 - Server icon URL
        - `{guild.banner}`               - Server banner URL
        - `{guild.created_at}`           - Creation date (DD Mon YYYY)
        - `{guild.created_at_timestamp}` - Creation Unix timestamp
      </TabsContent>

      <TabsContent value="User">
        - `{user.name}`                  - Username (or Last.fm username if context matches)
        - `{user.id}`                    - User ID
        - `{user.tag}`                   - Discriminator (e.g., 0001 or name)
        - `{user.mention}`               - User mention (`<@ID>`)
        - `{user.display_name}`          - Global display name or username
        - `{user.display_avatar}`        - Global avatar URL
        - `{user.avatar}`                - Avatar URL (from Last.fm if context matches)
        - `{user.guild_avatar}`          - Server-specific avatar URL
        - `{user.bot}`                   - "Yes" or "No"
        - `{user.boost}`                 - "Yes" or "No"
        - `{user.boost_since}`           - Boost start date
        - `{user.boost_since_timestamp}` - Boost start Unix timestamp
        - `{user.joined_at}`             - Join date
        - `{user.joined_at_timestamp}`   - Join Unix timestamp
        - `{user.top_role}`              - Highest role name
        - `{user.color}`                 - Color of highest role (Hex)
        - `{user.role_list}`             - List of roles (mentions)
        - `{user.join_position}`         - Join position with suffix (e.g., 1st)
        - `{user.join_position_raw}`     - Numeric join position
        - `{user.join_position_suffix}`  - Join position suffix only (st, nd, rd, th)
        - `{user.created_at}`            - Account creation date
        - `{user.created_at_timestamp}`  - Account creation Unix timestamp
      </TabsContent>

      <TabsContent value="Channel">
        - `{channel.name}`               - Channel name
        - `{channel.id}`                 - Channel ID
        - `{channel.mention}`            - Channel mention (`<#ID>`)
        - `{channel.topic}`              - Channel topic
        - `{channel.type}`               - Channel type (text, voice, etc.)
        - `{channel.category_id}`        - Parent category ID
        - `{channel.category_name}`      - Parent category name
        - `{channel.position}`           - Channel position
        - `{channel.slowmode_delay}`     - Slowmode delay in seconds
      </TabsContent>

      <TabsContent value="Lastfm">
        - `{user.scrobbles}`             - Total scrobbles
        - `{proper(user.scrobbles)}`     - Total scrobbles formatted (1,234)
        - `{user.plays}`                 - Total scrobbles (alias)
        - `{proper(user.plays)}`         - Total scrobbles formatted (alias)
        - `{user.url}`                   - Last.fm profile URL
        - `{user.artist_crown}`          - Crown emoji if artist crown owner
        - `{author}`                     - Last.fm author (Name#Discrim)
        - `{author.name}`                - Last.fm author name
        - `{author.nickname}`            - Last.fm author nickname
        - `{author.discriminator}`       - Last.fm author discriminator
        - `{track.name}`                 - Track name
        - `{lower(track.name)}`          - Track name in lowercase
        - `{track.url}`                  - Last.fm track URL
        - `{track.spotify_url}`          - Spotify URL for track
        - `{track.release_date}`         - Track release date
        - `{track.duration}`             - Track duration
        - `{track.plays}`                - Plays for this track
        - `{proper(track.plays)}`        - Plays for this track formatted
        - `{album.name}`                 - Album name
        - `{lower(album.name)}`          - Album name in lowercase
        - `{album.url}`                  - Last.fm album URL
        - `{album.cover}`                - Album cover image URL
        - `{artist.name}`                - Artist name
        - `{lower(artist.name)}`          - Artist name in lowercase
        - `{artist.url}`                 - Last.fm artist URL
        - `{artist.image}`               - Artist image URL
        - `{artist.plays}`               - Total plays for this artist
      </TabsContent>

      <TabsContent value="Leveling">
        - `{level.new_rank}`             - New rank reached
        - `{level.current_level}`        - Current level
        - `{level.user_xp}`              - Current total XP
      </TabsContent>

      <TabsContent value="Moderation">
        - `{moderator.name}`             - Moderator's username
        - `{moderator.id}`               - Moderator's ID
        - `{moderator.mention}`          - Moderator mention
        - `{moderator.tag}`              - Moderator's tag
        - `{moderator.display_name}`     - Moderator's display name
        - `{reason}`                     - Action reason
        - `{duration}`                   - Action duration
        - `{warns}`                      - Total warnings count
        - `{warns.suffix}`               - Warning count ordinal suffix
        - `{case}`                       - Case number
      </TabsContent>
    </Tabs>
